Tổng quan

Dịch vụ REST trong apps/api/ triển khai các đường đọc MVP-1 của docs/API_SPECIFICATION.md: 8 nhóm (7 + RAG), 26 đường dẫn / 27 thao tác. Tiền tố phiên bản /api/v1. Tài liệu tương tác tự sinh tại /docs (Swagger UI) và /redoc.

Kiến trúc 3 lớp: router (khai báo hợp đồng HTTP) → service (MarketService giữ nghiệp vụ + dữ liệu) → schema (Pydantic, hợp đồng vào/ra). Router không chứa logic; service hiện là kho trong bộ nhớ, tất định nên API chạy và kiểm thử được mà không cần TimescaleDB (xem KI-008).
Đổi sang CSDL thật: thay MarketService bằng repository SQLAlchemy trong apps/api/dependencies.py. Toàn bộ router và test hiện có giữ nguyên — hợp đồng không đổi.

Chạy máy chủ

# phát triển (tự nạp lại khi sửa mã)
uvicorn apps.api.main:app --reload

# trong Docker Compose
docker compose up api
curl localhost:8000/healthz

Lưu ý: POST /api/v1/backtests hiện trả về bản ghi giữ chỗ — phần nối engine thật hoàn tất khi lớp lưu trữ hoạt động (KI-008).

Quy ước phản hồi

Phân trang: mọi đường dẫn dạng danh sách trả {"items": [...], "total": n, "limit": l, "offset": o}. Tham số vào là ?limit=20&offset=0 (limit tối đa 200).
Lỗi: mã không tồn tại trả 404 kèm phong bì {"error": {"code": "NOT_FOUND", "message": ..., "detail": ...}}. Tham số sai trả 422 theo định dạng kiểm tra của FastAPI.
curl 'localhost:8000/api/v1/market/indices'
curl 'localhost:8000/api/v1/stocks?limit=10&offset=0&is_vn30=true'
curl 'localhost:8000/api/v1/stocks/FPT/ranking'
curl 'localhost:8000/api/v1/valuation/FPT/summary'
curl -i 'localhost:8000/api/v1/stocks/KHONGCO'   # -> 404 + phong bì lỗi

Kiểm thử

pytest -q tests/unit/test_api.py     # 17 bài: hệ thống, 7 nhóm, RAG, phân trang, 404

Bộ kiểm thử dùng fastapi.testclient.TestClient trên chính đối tượng app — không cần máy chủ đang chạy, không cần CSDL.
