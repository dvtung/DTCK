Bố cục kho mã

DTCK/
├── apps/                  # điểm chạy chương trình
│   ├── api/               # ★ dịch vụ FastAPI (REST /api/v1/*, T010)
│   ├── dashboard/         # giao diện Streamlit (T011)
│   └── worker/            # tác vụ nền + CLI (ingest/backfill/recompute)
├── src/                   # các package Python có thể import
│   ├── common/models/     # ★ mô hình SQLAlchemy — nguồn chân lý duy nhất (38 bảng)
│   ├── data/              # ★ nạp dữ liệu: provider/thu thập/kiểm tra/chuẩn hóa/chất lượng
│   ├── market/            # ★ quant: kỹ thuật/cơ bản/định giá/động lượng/rủi ro
│   ├── quant/             # ★ chấm điểm hệ số + tín hiệu (trọng số baseline §12)
│   │   ├── factors/       # ★ toán chấm điểm thô (T007)
│   │   └── scoring/       # ★ engine xếp hạng + payload giải thích (T008)
│   ├── backtesting/       # ★ engine kiểm thử cuốn chiếu (T009)
│   ├── rag/               # ★ nạp tin tức + truy xuát RAG (T012, chunking/nhúng/kho/retriever/rerank)
│   ├── agents/            # tác tử LangGraph (T013, bị chặn tới khi có baseline)
│   ├── ml/                # kho đặc trưng + mô hình (T014, bị chặn tới khi có baseline)
│   ├── portfolio/         # nghiệp vụ danh mục (đã dựng khung)
│   └── evidence/          # ★ engine bằng chứng §19 (T012)
├── database/
│   ├── migrations/        # môi trường Alembic + bản 0001_initial_schema
│   └── seeds/             # dữ liệu seed lặp lại an toàn (sở/ngành/VN30)
├── configs/sources.yaml   # ★ registry nhà cung cấp đọc được bằng máy (T002)
├── docs/                  # 13 đặc tả markdown (nguồn chân lý)
├── docs/htmldocs/         # ★ chính trang web tĩnh này
├── tests/unit/            # 175 kiểm thử đơn vị
├── memory-bank/           # tasks / current-state / decisions / changelog
├── docker/ docker-compose.yml
└── pyproject.toml requirements.txt .env.example

★ = đã triển khai và đã kiểm thử. Các package src/ còn lại mới chỉ dựng khung (file __init__.py rỗng) và sẽ mở khóa ở T011–T015.

Luồng xử lý của một yêu cầu (kiến trúc mục tiêu)

Nhà cung cấp→Thu thập→Kiểm tra→Chuẩn hóa→Cổng chất lượng→TimescaleDB
TimescaleDB→Engine quant→Chấm điểm→Backtest→API / Dashboard
Tin tức + báo cáo→RAG (Qdrant)→Tác tử→Mô hình ML→Khuyến nghị kèm bằng chứng
