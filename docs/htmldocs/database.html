Báo cáo tài chính lưỡng thời (bitemporal)

financial_statements mang valid_from / valid_to song song với period_end. Điều chỉnh hồi tố được xử lý bằng snapshot-diff: đóng dòng cũ, mở dòng mới — truy vấn as-of luôn an toàn, không nhìn trước tương lai.

Migration & seed — cách chạy

# nâng lên head (tạo 38 bảng + 12 hypertable)
alembic upgrade head
# kiểm tra / rollback
alembic current        # -> 0001_initial_schema (head)
alembic downgrade base && alembic upgrade head
# seed lặp lại an toàn
python -m database.seeds.run_all   # 3 sở, các ngành, 30 mã VN30
