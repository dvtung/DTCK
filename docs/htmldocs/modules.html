src/data — luồng nạp dữ liệu (T004 + T005)

Thiết kế: bản ghi độc lập nhà cung cấp chảy qua thu thập → kiểm tra → chuẩn hóa → lưu trữ → chấm điểm. Mọi giai đoạn đều là hàm thuần; đổi nhà cung cấp chỉ là thay đổi cấu hình trong sources.yaml.

class EODBar / IndexBar / NewsItem — dataclass trong records.py. Một ngày giao dịch OHLCV (+ symbol/date); một điểm in chỉ số; một bài báo (title, body, url, published_at, source).
class DataProvider — ABC trong providers/base.py: fetch_eod(symbols, start, end), fetch_index(...), fetch_news(since). Lớp con: FixtureProvider (dòng ngoại tuyến tất định qua seed_value()) và HttpJsonProvider (mẫu URL + trích xuất đường dẫn chấm).
registry.py — load_registry(), provider_specs(), get_spec(id), create_provider(source), enabled_by_role(role), fallback_chain(role). Đọc configs/sources.yaml.
collectors.py — collect_eod(provider, symbols, start, end) -> list[EODBar] · collect_index(...) · collect_news(provider, since). Wrapper mỏng với kiểm tra supports().
validators.py — validate_eod(bars, *, start, end) -> list[ValidationIssue] · validate_index(...) · validate_news(...). Kiểm tra: giá âm/bằng 0, high<low, thiếu ngày trong tuần, khóa trùng, timestamp tương lai. classify_issue() ánh xạ vấn đề tới chiều chất lượng.
normalizers.py — normalize_eod / normalize_index / normalize_news → dict sẵn sàng cho CSDL. resolve_stock_ids(conn, symbols) ánh xạ ticker thành id; _as_decimal / _as_date ép kiểu.
pipelines.py — ingest_eod(engine, provider, symbols, ...) -> IngestResult · ingest_index(...) · ingest_news(...). Điều phối toàn luồng; upsert dòng; chấm điểm chất lượng; đặt quality_passed.
quality.py — compute_quality(...) -> QualityScore, overall_from(dims) (trung bình có trọng số tái chuẩn hóa), freshness_score(latest, as_of) (Decimal), persist_quality(conn, score). Sáu chiều theo §39.

src/market/technical — các chỉ báo (T006)

Thiết kế: Python thuần túy, tất định. Đầu vào list[float] → đầu ra list[float | None] (None = giai đoạn khởi động). RSI dùng làm mượt Wilder; EMA gieo mầm bằng SMA; Bollinger dùng độ lệch chuẩn tổng thể.

sma(close, period) — trung bình trượt đơn giản trên cửa sổ liền trước.
ema(close, period) — trung bình trượt hàm mũ, gieo mầm bằng SMA của cửa sổ đầu, hệ số 2/(period+1).
rsi(close, period=14) — RSI Wilder; bằng 100 khi lỗ trung bình = 0, bằng 0 khi lãi trung bình = 0.
macd(close, fast=12, slow=26, signal=9) — trả về các tuple (đường, tín hiệu, histogram).
bollinger_bands(close, period=20, num_std=2) — trả về (trên, giữa, dưới); giữa = SMA, biên = ±num_std × độ lệch chuẩn tổng thể.
atr(high, low, close, period=14) — biên độ thật trung bình với làm mượt Wilder.
obv(close, volume) — khối lượng cân bằng; cộng khối lượng khi giá tăng, trừ khi giá giảm.
volume_sma(volume, period=20) — trung bình trượt của khối lượng giao dịch.
relative_strength(close, benchmark) — tỉ số từng phần tử close[i]/benchmark[i] để so sánh ngành/thị trường.

src/market/fundamental — các hệ số (T007)

Thiết kế: tỉ số vô hướng từ các trường báo cáo tài chính; mọi hàm trả về None khi mẫu số bằng 0 thay vì báo lỗi hay bịa giá trị.

revenue_growth(revenue) / eps_growth(eps) — chuỗi tăng trưởng cùng kỳ năm trước; None ở vị trí đầu và khi gốc = 0.
roe(net_income, equity) · roa(net_income, assets) · gross_margin / operating_margin / net_margin — các tỉ số sinh lời.
debt_to_equity(debt, equity) · interest_coverage(op_income, interest) — đòn bẩy; coverage trả về inf khi không nợ mà có lãi dương.
free_cash_flow(ocf, capex) · fcf_margin(fcf, revenue) · earnings_quality(net_income, ocf) — sức khỏe dòng tiền; quality > 1 nghĩa là lợi nhuận có tiền thật hậu thuẫn.

src/quant/factors — chấm điểm (T007)

Thiết kế: giá trị hệ số thô trở thành hạng bách phân 0–100 trong toàn vũ trụ, rồi pha trộn với trọng số baseline §12. Hệ số thiếu được loại ra kèm tái chuẩn hóa — không bao giờ bịa.

WEIGHTS — cơ bản 0.30 · kỹ thuật 0.20 · động lượng 0.15 · định giá 0.15 · chất lượng 0.10 · rủi ro 0.10. Giả định baseline, cần kiểm chứng qua backtest.
compute_factor_scores(stock, universe) — hạng bách phân từng hệ số cho một mã. compute_overall_score(scores, weights?) — trung bình có trọng số tái chuẩn hóa. rank_stocks(id→score) — xếp giảm dần, mã không điểm xếp cuối.

# -> {"fundamental": 80.0, "technical": None, ...}

ranking = rank_stocks({"FPT": overall, "VCB": 62.5})

src/quant/scoring — engine xếp hạng + giải thích (T008)

Thiết kế: lớp này bọc phần toán điểm thô của T007 và trả lời câu hỏi vì sao một mã xếp ở vị trí đó. Mỗi mã nhận một payload giải thích đầy đủ: đóng góp từng hệ số kèm tỷ lệ phần trăm, nhãn quyết định và độ tin cậy. Thuần túy, tất định — hệ số thiếu bị loại và điểm tổng được tái chuẩn hóa.

class FactorContribution — factor, raw_score, weight, weighted_score, share (phần trăm đóng góp trong điểm tổng). Trả lời: từng hệ số đóng góp bao nhiêu.
class ScoreDecomposition — overall_score, contributions, missing_factors (hệ số bị loại vì thiếu dữ liệu), weights_used (trọng số sau tái chuẩn hóa).
class StockRanking — stock_id, overall_score, decomposition, signal, confidence, factor_scores. Một dòng hoàn chỉnh cho bảng xếp hạng.
decompose_score(factor_scores, weights=None) -> ScoreDecomposition — phân rã điểm của một mã. score_universe(universe_scores, weights=None) -> list[StockRanking] — chấm điểm và xếp hạng toàn vũ trụ; mã không có hệ số nào bị đẩy xuống cuối.
build_signal_label(score) — ánh xạ điểm tổng sang POSITIVE / NEUTRAL / NEGATIVE (§44). build_confidence(overall, n_factors) — độ tin cậy giảm khi thiếu hệ số.
from src.quant.scoring.engine import score_universe

rankings = score_universe({
    "FPT": {"fundamental": 80.0, "technical": 60.0, "valuation": 20.0},
    "VCB": {"fundamental": 55.0, "technical": 70.0, "valuation": 65.0},
})
top = rankings[0]
print(top.stock_id, top.overall_score, top.signal, top.confidence)
for c in top.decomposition.contributions:
    print(f"  {c.factor}: {c.raw_score} x {c.weight} = {c.weighted_score} ({c.share:.1%})")
print("thieu:", top.decomposition.missing_factors)

src/backtesting — engine kiểm thử ngược (T009)

Thiết kế: tín hiệu ở giá đóng cửa ngày t → khớp lệnh ở giá mở cửa ngày t+1 (next-bar-open). Cách này loại bỏ thiên lệch nhìn trước tương lai theo cấu trúc, không dựa vào quy ước. Chi phí giao dịch (hoa hồng + trượt giá + thuế) trừ trực tiếp vào tiền mặt ở mỗi lần khớp lệnh.

class PriceBar / BacktestData — một dòng giá đã căn theo ngày; BacktestData gói toàn bộ chuỗi cùng danh sách mã.
class ExecutionCosts — commission_bps, slippage_bps, tax_bps. class Trade — symbol, side, trade_date, price, quantity, cost, pnl.
class EquityPoint — trade_date, equity, cash, positions_value. Đường cong vốn dùng để tính chỉ số đo.
class BacktestConfig — vốn ban đầu, chi phí, cửa sổ ngày, run_type. class BacktestResult — đường cong vốn + danh sách giao dịch + bộ chỉ số + cờ kiểm soát thiên lệch.
select_window(data, start_date, end_date) -> BacktestData — cắt dữ liệu theo cửa sổ ngày.
run_backtest(data, strategy, config) -> BacktestResult — hàm mô phỏng chính. strategy là hàm (data, i, state) -> {mã: trọng số 0..1} và chỉ được đọc dữ liệu tới hết ngày i. Phần chưa phân bổ nằm ở tiền mặt; bán khống ngoài phạm vi MVP.
walk_forward_windows(n, train_len, test_len, step?) — sinh các cặp (huấn luyện, kiểm tra) không chồng lấn. rolling_windows(n, window_len, step) — cửa sổ trượt thuần. class WalkForwardWindow — train_start/train_end/test_start/test_end, train_len/test_len.

src/rag + src/evidence — tin tức, RAG & bằng chứng (T012)

Thiết kế: tin tức chảy prin luồng: chunking (împărțire) → nhúng (embedding) → kho în bộ nhớ → truy xuát hibrid → rerank → Evidence (§19). Qdrant — optional (best-effort), fără dependențe.

embedding/hash_embed.py — class HashEmbedding — embed(text) -> list[float] (dim 128), model_name == "hash-embed-v1". Deterministic: același text → același vector.

retrieval/store.py — class MemoryVectorStore / QdrantAdapter — upsert(chunks), query(vector, top_k, filters), size; cosine distance, filter symbol/doc_type/source.
retrieval/retriever.py — class Retriever — retrieve(query, top_k, symbol, doc_type, source): hybrid vector + keyword + recency + source trust; returnează RankedDoc.
reranking/reranker.py — rerank(query, docs) — re-scoring RRF-style pentru ordine finală.
service.py — class RagService — ingest_news_items / search / evidence_for / status; singleton, inițiat prin rag_service.py.
src/evidence/engine.py — class Evidence, build_evidence, confidence_for — obiect §19: snippet, source, symbol, published_at, chunk_id, confidence 0..1.
