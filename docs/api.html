Tổng quan

Dịch vụ REST trong apps/api/ triển khai các đường đọc MVP-1 của docs/API_SPECIFICATION.md: 14 nhóm đường dẫn (market/stocks/fundamentals/technical/valuation/news/backtests + rag/evidence + agents/analysis + predictions/monitoring/auth), 39 đường dẫn / 40 thao tác. Tiền tố phiên bản /api/v1. Tài liệu tương tác tự sinh tại /docs (Swagger UI) và /redoc.

Kiến trúc 3 lớp: router (khai báo hợp đồng HTTP) → service (MarketService hoặc DbMarketService giữ nghiệp vụ + dữ liệu) → schema (Pydantic, hợp đồng vào/ra). Router không chứa logic và chỉ phụ thuộc protocol MarketSource (apps/api/services/market_source.py) — đó là lý do cùng một bộ router chạy được với kho trong bộ nhớ (mặc định, tất định, không cần hạ tầng) lẫn TimescaleDB thật.
Chế độ nguồn dữ liệu — biến môi trường MARKET_DATA_SOURCE (apps/api/dependencies.py): memory (mặc định) dùng MarketService tất định; db dùng DbMarketService đọc thẳng TimescaleDB; auto chọn CSDL khi SELECT 1 thông và bảng prices đã có dữ liệu, ngược lại tự về memory. Hợp đồng router và toàn bộ kiểm thử giữ nguyên ở cả ba chế độ.

Chạy máy chủ

# phát triển (tự nạp lại khi sửa mã) — nguồn dữ liệu: memory (mặc định) | db | auto
uvicorn apps.api.main:app --reload

# trong Docker Compose
docker compose up api
curl localhost:8000/healthz

Đường đọc CSDL: ở chế độ db/auto, các nhóm đọc index_prices, market_regimes, stocks, prices, factor_scores (kết quả job compute-scores), financial_statements/financial_ratios, valuation_daily, data_quality_scores, news+news_symbols và backtests/backtest_metrics/backtest_trades; chỉ báo kỹ thuật tính khi đọc, độ rộng thị trường suy ra từ prices. Bảng còn trống → danh sách rỗng hoặc 404 trung thực (không bịa dữ liệu); POST /api/v1/backtests vẫn là bản ghi giữ chỗ cho tới khi engine ghi được xuống CSDL.

Quy ước phản hồi

Phân trang: mọi đường dẫn dạng danh sách trả {"items": [...], "total": n, "limit": l, "offset": o}. Tham số vào là ?limit=20&offset=0 (limit tối đa 200).
Lỗi: mã không tồn tại trả 404 kèm phong bì {"error": {"code": "NOT_FOUND", "message": ..., "detail": ...}}. Tham số sai trả 422 theo định dạng kiểm tra của FastAPI.
curl 'localhost:8000/api/v1/market/indices'
curl 'localhost:8000/api/v1/stocks?limit=10&offset=0&is_vn30=true'
curl 'localhost:8000/api/v1/stocks/FPT/ranking'
curl 'localhost:8000/api/v1/valuation/FPT/summary'
curl -i 'localhost:8000/api/v1/stocks/KHONGCO'   # -> 404 + phong bì lỗi

Kiểm thử

pytest -q tests/unit/test_api.py             # 25 bài: hệ thống, các nhóm, RAG, phân trang, 404, agents, predictions
pytest -q tests/unit/test_market_data_source.py  # 11 bài: protocol + chọn nguồn memory/db/auto
pytest -q tests/integration/test_db_market.py    # 14 bài: đường đọc CSDL thật (tự skip khi không có DATABASE_URL)

Bộ kiểm thử dùng fastapi.testclient.TestClient trên chính đối tượng app — không cần máy chủ đang chạy, không cần CSDL. Bảng điều khiển (apps/dashboard) gọi API này trực tiếp qua HTTP (gỡ bao phân trang) với fallback trong tiến trình khi API tắt.
